01

Diagnostic test performance

Learn the 2×2 table. Use it to calculate sensitivity, specificity, positive predictive value (PPV) and negative predictive value (NPV). Then see how prevalence changes the predictive values.

Done when you can build a 2×2 table, calculate all four measures, say which row or column each one starts from, and explain how prevalence changes PPV and NPV.

1.1 · Why a 2×2 table

Why we need a 2×2 table

No test is perfect. Some infected animals test negative. Some uninfected animals test positive. The 2×2 table counts these outcomes so we can measure how well a test works.

To build the table, you need two things for every animal:

  • The true status (infected or uninfected). This comes from a reference standard. Section 02 explains why the reference standard must be trustworthy.
  • The test result (positive or negative) from the test you are evaluating.
1.2 · The 2×2 table

Build the table from 1,000 cattle

Example: 1,000 cattle are tested. 100 are infected and 900 are uninfected. Columns show the true status. Rows show the test result.

Four cells.
True positive (TP): infected, test positive.
False positive (FP): uninfected, test positive.
False negative (FN): infected, test negative.
True negative (TN): uninfected, test negative.
Two kinds of error.
False negative: an infected animal is missed. It may keep spreading infection.
False positive: an uninfected animal may face isolation, extra tests or movement restrictions.
Which error costs more depends on why you are testing.
Hypothetical teaching numbers. They are not performance claims for any real test.
1.3 · Four measures

Sensitivity, specificity, PPV and NPV

Pick a measure. The matching cells light up in the table, and the calculation appears below.

Sensitivity and specificity start from the true status. Read down the columns.
PPV and NPV start from the test result. Read across the rows.
Sensitivity (Se)

Does the test find infected animals?

Question: Of all infected animals, how many test positive?

Se = TP ÷ (TP + FN)

= 90 ÷ (90 + 10) = 90%

The test detects 90 of 100 infected cattle and misses 10. A highly sensitive test has few false negatives. A negative result from it is useful for ruling infection out.

Specificity (Sp)

Does the test clear uninfected animals?

Question: Of all uninfected animals, how many test negative?

Sp = TN ÷ (TN + FP)

= 855 ÷ (855 + 45) = 95%

The test clears 855 of 900 uninfected cattle and wrongly flags 45. A highly specific test has few false positives. A positive result from it is useful for ruling infection in.

Positive predictive value (PPV)

If the test is positive, is the animal infected?

Question: Of all test-positive animals, how many are infected?

PPV = TP ÷ (TP + FP)

= 90 ÷ (90 + 45) = 66.7%

About two in three positive cattle are infected. The other one in three are false positives.

Negative predictive value (NPV)

If the test is negative, is the animal free of infection?

Question: Of all test-negative animals, how many are uninfected?

NPV = TN ÷ (TN + FN)

= 855 ÷ (855 + 10) = 98.8%

About 99 in 100 negative cattle are uninfected. About 1 in 100 negative cattle is infected but missed.

A common misunderstanding. "90% sensitivity" does not mean a positive animal has a 90% chance of being infected. That question is about PPV. In the example, the sensitivity is 90% but the PPV is only 66.7%.
Predictive values depend on prevalence. Sensitivity and specificity are properties of the test. PPV and NPV also depend on how common infection is in the animals tested. Part 1.6 shows how much they change.
1.5 · Practice

Calculate the four measures

A new test is used on 400 cattle. The 2×2 table is below. Calculate each measure as a percent with one decimal. Then check your answers.

Show the working

Se = 80 ÷ (80 + 20) = 80 ÷ 100 = 80.0%

Sp = 270 ÷ (270 + 30) = 270 ÷ 300 = 90.0%

PPV = 80 ÷ (80 + 30) = 80 ÷ 110 = 72.7%

NPV = 270 ÷ (270 + 20) = 270 ÷ 290 = 93.1%

Se and Sp use the columns (100 infected, 300 uninfected). PPV and NPV use the rows (110 test-positive, 290 test-negative).

1.6 · Prevalence

How prevalence changes PPV and NPV

Sensitivity and specificity are properties of the test. PPV and NPV also depend on how common infection is in the animals tested. With Se and Sp fixed, higher prevalence gives higher PPV and lower NPV. Lower prevalence gives lower PPV and higher NPV.

Higher prevalence

PPV rises, NPV falls

Where infection is likely, a negative result is less reassuring. Avoiding false negatives matters most.

Lower prevalence

PPV falls, NPV rises

Where infection is rare, most positives are false positives. Avoiding false positives matters most.

1.6 · Formulas

PPV and NPV from prevalence, sensitivity and specificity

You can calculate PPV and NPV without a 2×2 table. Use sensitivity (Se), specificity (Sp) and prevalence (P). Enter each as a proportion, for example 0.10 for 10%.

PPV
PPV = (Se × P) ÷ [(Se × P) + (1 − Sp) × (1 − P)]
NPV
NPV = (Sp × (1 − P)) ÷ [((1 − Se) × P) + (Sp × (1 − P))]

Worked example. Se = 0.90, Sp = 0.95, P = 0.10.

PPV = (0.90 × 0.10) ÷ [(0.90 × 0.10) + (0.05 × 0.90)] = 0.090 ÷ 0.135 = 66.7%

NPV = (0.95 × 0.90) ÷ [(0.10 × 0.10) + (0.95 × 0.90)] = 0.855 ÷ 0.865 = 98.8%

Interpretation.
The PPV is 66.7%. Even though the test is 95% specific, a positive result means only a 66.7% chance that the animal is infected, because prevalence is low (10%). About one in three positive animals is a false positive.

The NPV is 98.8%. A negative result means a 98.8% chance that the animal is not infected. About 1 in 100 negative animals is infected but missed.
