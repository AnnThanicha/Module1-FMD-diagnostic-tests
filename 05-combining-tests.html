Combine diagnostic tests

Parallel (OR) testing raises sensitivity and lowers specificity. Serial (AND) testing raises specificity and lowers sensitivity.

Lecture

Serial and parallel diagnostic testing

One test is often not enough. Two tests can be combined in two ways. The way you combine them changes sensitivity, specificity and the type of error you make.

Serial testing · AND rule

Tests are done one after another. A later test is done only if the earlier test is positive.

  • Decision rule: a sample is positive only if all tests are positive. If any test in the sequence is negative, the condition is ruled out.
  • Statistical effect: specificity and positive predictive value go up. Sensitivity goes down. It reduces false positives.
  • Best used for: confirming a diagnosis (ruling in a disease), when you need to be sure a positive result is real.
  • Trade-off: it takes more time. It uses fewer resources at the start, because not every animal needs every test.

Parallel testing · OR rule

Two or more tests are done at the same time, or around the same time.

  • Decision rule: a sample is positive if any single test is positive. All tests must be negative to call the sample negative.
  • Statistical effect: sensitivity and negative predictive value go up. Specificity goes down. It reduces false negatives.
  • Best used for: first screening, or emergencies where missing a true case has a high cost.
  • Trade-off: results come quickly, so decisions can be made at once. But false positives are more likely.

How to calculate combined sensitivity and specificity

For two tests, A and B, that make errors independently of each other:

Serial (AND)Parallel (OR)
Combined sensitivitySeA × SeB1 − (1 − SeA) × (1 − SeB)
Combined specificity1 − (1 − SpA) × (1 − SpB)SpA × SpB
WhyAn infected animal must test positive on both tests. A healthy animal is wrongly called positive only if both tests give a false positive.An infected animal is missed only if both tests are false negative. A healthy animal must test negative on both tests.
Example
A: Se 90%, Sp 95%
B: Se 80%, Sp 98%		Se = 0.90 × 0.80 = 72.0%
Sp = 1 − (0.05 × 0.02) = 99.9%		Se = 1 − (0.10 × 0.20) = 98.0%
Sp = 0.95 × 0.98 = 93.1%

Check the pattern. Serial testing lowers sensitivity (90% and 80% become 72%) and raises specificity (95% and 98% become 99.9%). Parallel testing does the opposite. These formulas assume the two tests make errors independently. If they share errors, for example because both react to the same antibody, the real values are less favourable.

Case: Confirming FMD in suspected pigs

Scenario. You are a veterinary officer in East Java, Indonesia. You receive a report of pigs showing clinical signs suspected to be associated with foot-and-mouth disease (FMD). You visit the farm and collect appropriate samples from the suspected animals. You now need to confirm whether the animals are infected with FMD virus using diagnostic testing.

  1. Which two diagnostic tests will you choose? Why do you choose these tests?
  2. Will you conduct the tests in parallel or in serial? Why?
  3. What are the sensitivity and specificity of the parallel or serial testing?

Presentation. Answer these questions in your presentation. Show the tests you chose and why, the rule you used (parallel or serial) and why, and the combined sensitivity and specificity with your calculation.
